# bee-movies-sql-project

A SQL project using the DVD Rental dataset to practice database querying and data analysis.

## Files

| File | Description |
| --- | --- |
| `Le_Son_LV1_Project_04_Bee_Movies.sql` | SQL queries and analysis for the Bee Movies project |
| `import-data.sql` | Script to import and set up the database schema |
| `dvdrental.tar` | PostgreSQL backup of the DVD rental sample database |
| `ERD.xlsx` | Entity-relationship diagram for the DVD rental database |

## Concepts covered

- Relational database querying with SQL
- Joins, aggregations, and filtering
- Entity-relationship modelling
- Database import and restoration from a backup
