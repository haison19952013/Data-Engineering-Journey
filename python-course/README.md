# Python Fundamentals Course

Early Python learning materials and programming assignments covering foundational data structures and string manipulation.

## Files

| File | Description |
| --- | --- |
| `Basic Coding Assignment.ipynb` | Introductory Python coding exercises |
| `Lists - PP Assignment.ipynb` | Assignments focused on Python list operations |
| `Strings - PP Assignment.ipynb` | String manipulation exercises and challenges |
| `Other Data Structures - PP Assignment.ipynb` | Exercises covering dictionaries, sets, and tuples |

## Concepts covered

- Basic Python syntax and control flow
- List operations and comprehensions
- String methods and formatting
- Python built-in data structures (dict, set, tuple)
