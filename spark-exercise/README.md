# Apache Spark Exercises

A focused Spark exercise using PySpark's standalone application API.

## Files

| File | Description |
| --- | --- |
| `SimpleApp.py` | A minimal PySpark application demonstrating how to create a SparkContext and run a basic Spark job |

## Concepts covered

- Creating a `SparkConf` and `SparkContext`
- Reading data into an RDD
- Running simple Spark transformations and actions
- Standalone PySpark application structure
