- Experience with **Kafka, Spark, PostgreSQL, MongoDB, Airflow, and dbt**
- Projects covering **data ingestion, transformation, orchestration, analytics, and deployment**
- A mix of **fundamentals, guided labs, and larger portfolio-style projects**
