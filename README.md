# Data Engineering Journey

This repository is a professional portfolio of hands-on data engineering projects, labs, and practice exercises. It shows my progression from core data skills to end-to-end pipeline design across batch processing, streaming, data modeling, and cloud tooling.

## What this repository highlights

- Practical work with **Python, SQL, Bash, and Pandas**
- Experience with **Kafka, Spark, PostgreSQL, MongoDB, Airflow, and dbt**
- Projects covering **data ingestion, transformation, orchestration, analytics, and deployment**
- A mix of **fundamentals, guided labs, and larger portfolio-style projects**

## Repository structure

- `installation_guide/` – setup notes and lab materials for Kafka, Spark, Airflow, and PostgreSQL
- `Python_PostgreSQL/` and `Python_Exception/` – foundational Python practice for database access and error handling
- `sql-case-when-exercises/` and `Spark_exercise/` – focused exercises for SQL and Spark concepts
- `Python_course/` – early Python learning materials and assignments

## Summary

This repository is intended to demonstrate consistent learning, practical implementation, and growing depth in data engineering. It combines foundational exercises with more complete projects that reflect how I approach data pipelines, streaming systems, and analytics workflows.
