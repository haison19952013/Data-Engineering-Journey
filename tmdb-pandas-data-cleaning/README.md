# tmdb-pandas-data-cleaning

Pandas-based data cleaning and analysis of the TMDb (The Movie Database) movies dataset.

## Files

| File | Description |
| --- | --- |
| `main.ipynb` | Jupyter notebook with data cleaning and analysis steps |
| `tmdb-movies.csv` | Raw TMDb movies dataset |
| `tmdb-movies-top10-profit.csv` | Top 10 movies by profit |
| `tmdb-movies-vote-average-gt75.csv` | Movies with a vote average above 7.5 |
| `tmdb-movies-genres-count.csv` | Count of movies per genre |
| `tmdb-movies-genres-most.csv` | Most common genres |
| `tmdb-movies-release-date-sort.csv` | Movies sorted by release date |
| `tmdb-movies-revenue-adj-max.csv` | Movies with maximum adjusted revenue |
| `tmdb-movies-revenue-adj-min.csv` | Movies with minimum adjusted revenue |
| `tmdb-movies-cast-most.csv` | Most frequently appearing cast members |
| `tmdb-movies-director-most.csv` | Most prolific directors in the dataset |

## Concepts covered

- Data loading and exploration with Pandas
- Cleaning and normalising messy CSV data
- Filtering, sorting, and aggregating DataFrames
- Exporting cleaned results to CSV files
