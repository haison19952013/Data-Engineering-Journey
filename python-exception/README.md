# Python Exception Handling

Foundational examples of Python exception handling patterns.

## Files

| File | Description |
| --- | --- |
| `open_file.py` | Catching `FileNotFoundError` when opening a missing file using `try/except` |
| `linux_interaction.py` | Raising `RuntimeError` for platform-specific code and using `finally` for cleanup |
| `low.py` | Using `assert` to enforce a condition and raise `AssertionError` |

## Concepts covered

- `try / except / finally` blocks
- Catching specific exception types (e.g. `FileNotFoundError`)
- Raising exceptions with `raise`
- Using `assert` for defensive checks
