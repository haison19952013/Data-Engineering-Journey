# python-postgresql-labs

Practical lab exercises for working with PostgreSQL using Python, covering data scraping, database operations, and end-to-end pipeline construction.

## Files

| File | Description |
| --- | --- |
| `config.py` | Database connection configuration |
| `db_process.py` | Database utility functions for insert, update, and query operations |
| `crawl_data.py` | Script to scrape and collect product data |
| `utils.py` | Shared utility helpers |
| `main.ipynb` | Jupyter notebook walkthrough of the lab exercises |

## Concepts covered

- Connecting Python to PostgreSQL with `psycopg2`
- Web scraping and storing results in a relational database
- Structuring a small ETL pipeline
- Database utility design patterns
