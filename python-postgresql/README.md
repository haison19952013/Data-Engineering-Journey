# python-postgresql

Hands-on examples of connecting Python to PostgreSQL using `psycopg2`.

## Files

| File | Description |
| --- | --- |
| `connect.py` | Establish a basic database connection |
| `create_table.py` | Create a table in PostgreSQL |
| `insert.py` | Insert rows into a table |
| `fetch_one.py` | Fetch a single row |
| `fetch_many.py` | Fetch multiple rows with cursor |
| `fetch_all.py` | Fetch all rows from a query |
| `update.py` | Update existing records |
| `delete.py` | Delete records from a table |
| `transaction.py` | Manage transactions with commit and rollback |
| `callfunction.py` | Call a PostgreSQL function from Python |
| `call_stored_procedure.py` | Execute a stored procedure |
| `read_blob.py` | Read binary large objects (BLOBs) from the database |
| `write_blob.py` | Write BLOBs to the database |
| `config.py` | Database connection configuration |
| `main.ipynb` | Jupyter notebook walkthrough of the examples |

## Concepts covered

- Connecting to PostgreSQL with `psycopg2`
- CRUD operations (Create, Read, Update, Delete)
- Transaction management
- Stored procedures and functions
- Binary data (BLOB) handling
