# sql-case-when-exercises

Exercises focused on SQL `CASE WHEN` expressions using a college football dataset.

## Files

| File | Description |
| --- | --- |
| `college_football_players.csv` | Dataset of college football players used for SQL practice |
| `config.py` | Database connection configuration |
| `db_process.py` | Database utility functions |
| `crawl_data.py` | Script to load and prepare data for querying |
| `utils.py` | Shared utility helpers |
| `main.ipynb` | Jupyter notebook with SQL `CASE WHEN` exercise walkthroughs |

## Concepts covered

- SQL `CASE WHEN` expressions for conditional logic
- Data classification and bucketing in SQL
- Aggregations combined with conditional statements
- Loading CSV data into PostgreSQL for analysis
